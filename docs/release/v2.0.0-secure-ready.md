## Security-baseline controls (Wave 2)

### Authentication / session

- [x] bcrypt cost ≥ 12; demo passwords hashed at rest
- [x] Password strength on register/create/update
- [x] RS256 required in `NODE_ENV=production` (no HS256 fallback)
- [x] Access JWT short TTL; refresh rotate/revoke
- [x] httpOnly refresh cookie; access token memory-only (SPA)
- [x] CSRF header on cookie refresh (`X-Requested-With`)
- [x] Generic auth failures (`Invalid credentials`)

### Authorization / files

- [x] `HasRoleGuard` loads role from DB
- [x] `ROLE_RANK` on escalate / role assign
- [x] File ownership on get/download/delete/list
- [x] Share PUT/DELETE owner or admin
- [x] Upload path sanitize + magic MIME + size limit
- [x] `assertPathInsideUploads` before `sendFile`

### Transport / infra / ops

- [x] TLS compose overlay + HSTS + `tls-smoke.sh`
- [x] Secure cookies when `COOKIE_SECURE=true`
- [x] Postgres not published on default prod compose
- [x] nginx rate limit on `/api/auth/` + Nest throttler
- [x] Non-root backend/frontend containers
- [x] `mem_limit` on compose services
- [x] Permissions-Policy header
- [x] TypeORM SQL logging off in production; log redaction helpers

### Accepted residuals

- [x] Sequential entity IDs (seed compatibility) — see [accepted-residuals-m8.md](../security/Cycle-1/Remediation/accepted-residuals-m8.md)
- [x] Access JWT remains valid until `exp` after logout (refresh revoked)
- [x] Lab demo account cleartexts documented for login only (hashes in DB)
