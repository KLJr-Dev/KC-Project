| Domain | Capability (must still work for legitimate roles) |
|--------|---------------------------------------------------|
| User Management | Register, login, logout, JWT sessions, profile |

## Intentionally remediated (must fix for v2.0.0)

Mapped from Cycle-1 findings. Full detail: [v2.0.0-remediation.md](../security/Cycle-1/Remediation/v2.0.0-remediation.md).

| ID | Sev | Weakness | Secure expectation |
|----|-----|----------|--------------------|
| F-02 | Critical | File IDOR | Other users’ files → **403** |
| F-03 | Critical | JWT role forge / `kc-secret` | Forged admin → **403**; DB role authoritative |
| F-05 | Critical | Postgres on host + defaults | **5433 closed** on host; strong creds |
| F-01 | High | Open Swagger | Prod `/api/docs` not public |
| F-04 | High | Predictable public shares | Guessable `share-N` fails; expiry enforced |
| F-10 | High | Admin DELETE / audit-logs ungated | User JWT → **403** |
| F-08 | Medium | Login user enumeration | Identical failure messages |
| F-09 | Medium | No `exp` / logout no-op | Short-lived access; logout revokes (M4 complete) |
| F-12 | Medium | Anonymous `/dev` | Gated or absent in prod |
| F-06 | Low | Missing headers / stack disclosure | Baseline headers at nginx |
| F-07 | Low | CORS `*` | Explicit allowlist |
| F-11 | Info–Low | Demo passwords in prod UX | Flagged / stripped in prod builds |
| F-13 | Info | Version / CWE strings in errors | Stable client errors |
