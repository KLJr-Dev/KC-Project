# Cycle-10 topology — `v2.10.0` (Blue)

Sole public: **`:80`→HTTPS** and **`:443`**. Zones via NIC + `internal: true`.  
`c10-fw` FORWARD default-deny is a routed-traffic safety net (same-bridge L2 does not hit FORWARD). Real hard gates: bastion INPUT (integrate-only), no docproc on `net_data`.

```text
Internet ──443/80──► c10-edge (DMZ)
                      │
                      ├── portal / api (APP)
                      │         │
                      │         └── docproc (APP only) ──X── db-archive (DATA)
                      │
                      └── integrate ──22──► bastion (MGMT)
```

See [v2.10.0-reachability-matrix.md](../security/Cycle-10/Dev/v2.10.0-reachability-matrix.md).
