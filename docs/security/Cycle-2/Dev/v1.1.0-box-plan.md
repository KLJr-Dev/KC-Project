## 1. Concept

| Field | Choice |
|-------|--------|
| Scenario | **C′ — Admin-gated database** |
| Product | Same Nest/Next/Postgres/nginx surface as v2.0.0 |
| Style | OSCP proof: identity + `cat` analogue |
| Flag count | **3** (user / admin / db-root) |
| Flag shape | 32-char lowercase hex (MD5-looking) |
| Flag homes | `.txt` on disk (uploads) + one DB row |
| New routes | **None** |
| Sidecars (SSH/FTP) | **Not in v1.1.0** — note only for future cycles |

### Proof rules (scoring)

A proof is valid only if evidence shows **both**:

1. **Identity** — who you are in that tier (`/api/auth/me`, JWT `sub`+`role`, Admin UI, or `SELECT current_user` for DB).
2. **Flag body** — exact 32-hex from the file or row.

Hash alone = invalid. Wrong user with right hash = invalid.

| OSCP | KC v1.1.0 |
|------|-----------|
| `whoami` → user · `cat ~/local.txt` | Low-priv session + download/read **local.txt** |
| `whoami` → root · `cat /root/proof.txt` | Admin session + download/read **proof.txt** |
| (machine root / DB) | `psql` as unlocked role + `SELECT` proof row |

## 3. Intended attack path

```text
[1] RECON
    nmap     → 8080/http, 5433/postgresql (open; default creds FAIL)
    gobuster → /api /admin /share /api/health [/api/docs if CTF overlay enables Swagger]

[2] FOOTHOLD
    Username enum (users directory residual OK) + hydra/ffuf on POST /api/auth/login
    CTF overlay: relax auth rate-limit enough for lab hydra
    → low-priv JWT

[3] USER PROOF  ≈ local.txt
    Horizontal access to file 9104:
      • Preferred plant path: re-open GET/download ownership on files
        OR keep/document share-create without file ownership
    Evidence: /auth/me (or JWT) + local.txt body

[4] PRIV ESC
    Exactly ONE vertical break (document which):
      • HasRoleGuard trusts JWT role again, OR
      • HS256 + weak JWT_SECRET (jwt_tool / forge), OR
      • Drop @HasRole on one admin read (audit / files list)
    Pick during implementation; default lean: HS256 weak secret + JWT role trust
    so hydra/jwt tools feel natural.

[5] ADMIN PROOF  ≈ proof.txt
    As admin: list/download admin-owned proof.txt
    Evidence: admin identity + proof.txt body

[6] DB PROOF  (admin-gated)
    Admin loot: DB password in admin-only place
      (proof.txt companion line, audit details, or admin-only ops note file)
    psql -h TARGET -p 5433 -U postgres -d kc_prod
    SELECT current_user; SELECT … flag …;
    Evidence: current_user + 32-hex
```
