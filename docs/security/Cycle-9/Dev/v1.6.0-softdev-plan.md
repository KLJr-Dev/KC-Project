## Workstreams

### W1 — Edge rewire (`backend` + `infra`) — **first**

| Task | Detail |
|------|--------|
| nginx | Remove `proxy_pass http://intake:8000` for `/api/intake/`; route `/api/intake/` under Nest `/api/` (or Nest-owned location) |
| Nest BFF module | Thin proxy: `IntakeBffController` (or equiv.) forwards to `http://intake:8000` |
| Insecure headers | If client sends `X-User-Id` / `X-User-Role` → forward; else fill from JWT claims |

| Markers | `CYCLE9-PLANT` on header forward path |
