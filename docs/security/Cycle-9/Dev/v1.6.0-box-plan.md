## Story (graded path)

1. Recon — `:8080`, `/api/intake/*` (via Nest), `/admin/security`, demo users.  
2. Honeypot timebox — `…/v1/internal/debug` → **services alerted**; move on.  
3. Login (demo or register).  
4. Enumerate **`/onboarding-requests`** — sequential IDs → **IDOR** → **F1**.  
5. Observe Nest BFF → Intake hop — spoof **`X-User-Id` / `X-User-Role`** → **F2**.  
6. Race **`PUT …/status`** to `approved` (or approve via F2 privilege).  
7. **`GET …/export?file=`** with path traversal (`../`, `%2e%2e%2f`, nested) → **F3**.  
8. **`GET …/security/events`** → leak → **F4**.  
9. Stop. AppSec writeup.

## Surfaces (detail)

### FastAPI — see [intake-openapi-stub.yaml](intake-openapi-stub.yaml)

Schema sketch: `onboarding_requests` (id, employee_email, department, national_id_last4, manager_note, status, assignee_id, export_relpath, created_at).

Export plant: intended files under e.g. `/app/exports/{id}/`; F3 file outside that tree; `file` query joined without confinement on insecure tip. Pending requests: export **403/404**. Approved: join + read (traversal works).

### Nest BFF

- Routes under `/intake/*` (proxied as `/api/intake/*` from browser).  
- Insecure (locked): after JWT verify, **forward client `X-User-*` if present, else fill from JWT claims**. Nest-native routes still use DB `HasRoleGuard`; BFF hop is the weak boundary.  
- Blue: never forward client `X-User-*`; Intake verifies RS256.

### Frontend

- `/intake` — search + list/submit onboarding requests  
- `/intake/queue` — approval UI  
- `/admin/security` — theatre + events link

## Hint ladder

1. Onboarding lives under the Intake API prefix — but the edge may be a **BFF**, not the Python process itself.  
2. Sequential HR object IDs are worth walking.  
3. Identity crossing a team boundary often becomes **headers**.  
4. `pending` → `approved` hates concurrent writers.  
5. “Export package” endpoints that take a **filename** are classic traversal labs (`../`, `%2e%2e%2f`).  
6. Bolted-on “security events” feeds are worth reading carefully.  
7. If a debug path says **services alerted**, believe it and move on.
