# Cycle-9 STRIDE-lite — `v1.6.0`

**Scope:** Nest BFF (Platform) → FastAPI Onboarding squad; onboarding-requests + export + SIEM theatre.  
**Companion:** [cycle-9-decisions.md](cycle-9-decisions.md)

| Element | Threat | Mitigation on Blue `v2.6.0` |
|---------|--------|------------------------------|
| **S** Spoofing | Forge `X-User-Id` / `X-User-Role` across team hop | Intake verifies RS256; ignore spoof headers |
| **T** Tampering | Status race; export `file=` path traversal | Atomic status; resolve + base-dir confinement |
| **R** Repudiation | Incomplete Intake audit / SIEM gaps | Log authz + request-ID; redact events |
| **I** Info disclosure | Request IDOR (HR PII); SIEM leak; health fingerprint | Ownership checks; redacted events |
| **D** DoS | Unbounded `/api/intake/` | nginx `limit_req` (Wave B) |
| **E** Elevation | Header role → approve → export | Real JWT + role checks inside Intake |

**Trust boundaries:** browser → nginx → **Nest BFF** → **FastAPI** → `kc_intake`. FastAPI not on published nginx location.

**Out:** network pivots, shell EoP, Intake SQLi, Ops Documents LFI re-break.
