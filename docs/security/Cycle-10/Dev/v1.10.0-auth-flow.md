# Auth / access flow — `v1.10.0` (insecure)

Canonical diagram: [c10-v1.10.0-auth-flow.md](../../../diagrams/c10-v1.10.0-auth-flow.md)

## Roles (existing RBAC)

| Role | Graded packets? | How obtained on insecure tip |
|------|-----------------|------------------------------|
| anonymous | no | default |
| `user` | **403** | Open register (noise) |
| `moderator` | **yes** | Hidden access dir → document-portal request form |
| `admin` | yes (not required) | Not granted by Stage 0 |

## Graded access sequence

1. Discover HTML comment on `/` (and edge static) → **`/staff-access/`**.  
2. Submit access request → Nest `POST /access-requests` grants **`moderator`** (never admin).  
3. Login via normal Nest auth (JWT / refresh as today).  
4. UI `/packets` lists/uploads; API enforces `@HasRole(['moderator','admin'])`.  
5. Upload triggers `docproc` helper (service identity Nest→helper; player shell is helper OS user).
