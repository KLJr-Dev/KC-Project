# Reachability matrix — `v1.10.0` (insecure tip)

Default: **DENY** cross-zone. SoftDev enforces via **NIC membership**, `internal: true` on DATA/CORP/MGMT, bastion INPUT iptables, and **HTTPS-only host publish**. `c10-fw` FORWARD is default-DROP (+ ESTABLISHED); same-bridge traffic does not traverse fw.

| Source | Destination | Proto / intent | SoftDev |
|--------|-------------|----------------|---------|
| Internet | `edge` | HTTPS `:443→443` (weak) | **Published — sole host face** |
| Internet | `partners` / `honeypot` / APP/DATA/CORP/MGMT | any | **Deny** (no HostPort) |
| Internet | prod `nginx` `:8080` | HTTP | **Deny under lab overlay** (`ports: !reset`) |
| edge | portal / api | HTTP on `net_app` | Allow (shared NIC) |
| api | docproc helper | HTTP `:9090` | Allow (`net_app`, `DOCPROC_URL`) |
| api | intake | HTTP BFF | Allow (prod nets) |
| docproc | db-archive | PG `:5432` | Allow (`net_data` exception) |
| integrate | bastion | SSH `:22` | Allow (`net_mgmt` + bastion INPUT) |
| ws-admin / other CORP | bastion | SSH | **Deny** (no MGMT NIC) |
| anonymous | packets API | upload | **Deny** (JWT + moderator) |

Secure `v2.10.0` removes lab exceptions; zone shape remains.
