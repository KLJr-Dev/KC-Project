## Per-finding detail

### C8-F01 — Intake SQLi (must-close)

**v1.5.0 state:** Authenticated `GET /api/intake/search?q=` allows UNION-based extraction of `public.mail_users` including F1.

**v2.5.0 intent:** Keep Intake search as a product feature. Use parameterized queries (or ORM). Remove graded flag row / exploitable plant from secure seed. Flags remain on `ctf/v1.5.0` only.

### C8-F02 … C8-F05 — Overlay chain (must-close on tip)

**v1.5.0 state:** `docker-compose.cycle8.yml` publishes FTP `:21`, Cowrie `:22`, edge with sudo nano, internal Samba/mail with F2–F5 plants.

**v2.5.0 intent:** Default `docker-compose.prod.yml` never publishes overlay services (`assert-cycle8-unpublished.sh`). Overlay + plants stay on **`ctf/v1.5.0`** for replay. Tip UI / version → `v2.5.0`. Northwind skin retained.

### C8-F06 — Cowrie decoy

Info observation. Accepted residual once overlays unpublished on secure tip.
