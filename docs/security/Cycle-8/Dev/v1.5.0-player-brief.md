# Cycle-8 player brief — `v1.5.0` (Northwind Intake)

**Audience:** Red players / students  
**Spoilers:** Progressive hints only — no flag values, no full exploit recipes.  
**Examiner GT:** [v1.5.0-ground-truth.md](v1.5.0-ground-truth.md)

---

## Objective

You are assessing a **Northwind** employee portal / ops intake stack. Recover **five** graded proofs. Expect a **multi-session** engagement (recon → dump/crack/spray → shell → PrivEsc → pivot).

| ID | Theme |
|----|--------|
| F1 | Data store / query trust boundary |
| F2 | Weak file-transfer auth after spray |
| F3 | Interactive foothold (listener matters) |
| F4 | Local privilege escalation |
| F5 | Internal file-share and/or mail (pivot) |

Flag format: `OS{` + 32 lowercase hex + `}`.

Host flags require a **valid interactive** path. You will see **many** usernames, hashes, and tempting passwords — most are noise. Cracked material for one service often does **not** unlock another.

## Lab start

```bash
docker compose -f infra/docker-compose.prod.yml -f infra/docker-compose.cycle8.yml up -d --build
```

- App: `http://TARGET:8080` (Host-Only IP)  
- Demo accounts: [demo-users.md](../../../deploy/demo-users.md) (product UI only — not a free shell)  
- Full port scan recommended  

## Rules of engagement

- **In scope:** Portal + discovered TCP on the lab target; pivot to internal hosts only reachable from foothold  
- **Out of scope:** DoS; other students; published Postgres on secure demos; re-breaking Cycle-6/7 closed controls; real AD / Windows outside this lab  
- Do not “fix” plants on this tip — Blue is `v2.5.0` after Red  
- Timebox rabbit holes; document false paths  

## Suggested session split

| Day | Focus |
|-----|--------|
| 1 | Recon, API/data finding, crack + spray, post-FTP proof |
| 2 | Foothold (listener), PrivEsc, dual-home discovery |
| 3 | Pivot (share + mail), OSCP-style writeup |

## Progressive hints

<details>
<summary>Hint 1</summary>
Small intake/search APIs behind the main portal often deserve the same attention as a separate host.
</details>

<details>
<summary>Hint 2</summary>
Hashes in a dump may belong to mail or another store — not necessarily the first service you spray.
</details>

<details>
<summary>Hint 3</summary>
Forgotten file-transfer services frequently have weak passwords worth a dedicated spray.
</details>

<details>
<summary>Hint 4</summary>
Open ports that look like classic admin protocols are not always real footholds.
</details>

<details>
<summary>Hint 5</summary>
If you can write content the web server will execute, prepare a listener before you trigger a callback.
</details>

<details>
<summary>Hint 6</summary>
After a user shell, always check sudo (and GTFOBins).
</details>

<details>
<summary>Hint 7 (almost spoiler)</summary>
Bring cracked mail credentials inward — some proofs speak SMB and SMTP only from the foothold network.
</details>
