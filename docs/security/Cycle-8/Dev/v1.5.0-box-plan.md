## Hint ladder (player brief)

1. Portal APIs often front small services — search/filter params matter.  
2. Hashes in a dump are not always for the service you spray first.  
3. Weak file-transfer accounts still show up on full port scans.  
4. Not every SSH-looking port is real.  
5. Writable web content + a listener on Kali is a classic foothold.  
6. After a user shell, check sudo / GTFOBins.  
7. Mail and file-share services may wait one hop inward — bring creds you already cracked.
