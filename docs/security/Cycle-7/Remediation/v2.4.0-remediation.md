## Per-finding detail

### C7-F01 — Ops Documents LFI (must-close)

**v1.4.0 state:** Authenticated `GET /api/ops/documents?path=` uses `path.join(libraryRoot, relPath)` without canonicalization or stay-under-root. `../plants/cycle7-f1.txt` returns F1.

**v2.4.0 intent:** Keep Ops Documents. Resolve paths and reject anything outside `ops-docs/library`. Remove plant file and tip F1 constant / flag string. Flags remain on `ctf/v1.4.0` only.

### C7-F02 … C7-F05 — Overlay chain (must-close on tip)

**v1.4.0 state:** `docker-compose.cycle7.yml` publishes FTP `:21`, bastion `:2222`, Cowrie `:2223`, and internal jump with graded plants F2–F5.

**v2.4.0 intent:** Default prod compose never publishes those services/ports (`assert-cycle7-unpublished.sh`). Overlay + plants stay available for **archive replay** on `ctf/v1.4.0`, not for secure demos. Tip UI / version string → `v2.4.0`.

### C7-F06 — Dual SSH / honeypot

Info observation. Not a secure-tip defect once overlays are unpublished. Accepted residual / archive realism.
