## Objective

Recover **five** graded proofs on the intentional insecure tip. Expect a **multi-session** engagement (recon → foothold → PrivEsc → pivot).

| ID | Theme |
|----|--------|
| F1 | Web path / document trust boundary |
| F2 | Forgotten file service loot |
| F3 | Interactive user foothold |
| F4 | Local privilege escalation |
| F5 | Reach a host your Kali cannot see directly |

Flag format: `OS{` + 32 lowercase hex + `}`.

Host flags require a **valid interactive** path (OSCP-style — not “download the flag without a shell” where a shell is the intended proof).

## Lab start

```bash
docker compose -f infra/docker-compose.prod.yml -f infra/docker-compose.cycle7.yml up -d --build
```

- App: `http://TARGET:8080` (Host-Only IP in lab)  
- Demo accounts: [demo-users.md](../../../deploy/demo-users.md)  
- Full port scan recommended — more than `:8080` may be listening  

## Rules of engagement

- **In scope:** Web app, discovered TCP services on the lab target, pivot to internal lab hosts reachable only from foothold  
- **Out of scope:** DoS; attacking other students; published Postgres on secure demos; re-breaking Cycle-6 Preview/CSRF; Notes XSS; real-world AD outside this lab  
- Do not “fix” plants on this tip — Blue is `v2.4.0` after Red  
- Timebox rabbit holes; document false paths in your notes  

## Suggested session split

| Day | Focus |
|-----|--------|
| 1 | Recon, web finding, file service, foothold user |
| 2 | PrivEsc, identify dual-home, pivot, final proof |
| 3 | Writeup + evidence |

</details>

</details>
