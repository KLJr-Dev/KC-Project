## Per-finding detail

### C6-F01 — SSRF (Link Preview)

**v1.3.0 state:** Authenticated `POST /preview` fetches arbitrary http(s) URLs with no allowlist. Red reached Nest on container loopback `:4000` and `GET /internal/cycle6-flag` for F1.

**v2.3.0 intent:** Keep Preview as a product feature. Reject loopback, link-local, and cloud metadata destinations (document private-range policy). Remove `/internal/cycle6-flag` and F1 constant from tip. Flags remain on `ctf/v1.3.0` only.

### C6-F02 — CSRF (bookmarks)

**v1.3.0 state:** `/auth/bookmarks` uses `kc_refresh` cookie without `assertCsrfHeader`. UI `POST` and `GET …/save` both state-changing. Refresh remains CSRF-gated — intentional contrast exploited in Red writeup.

**v2.3.0 intent:** Require CSRF on all bookmark mutations. Prefer removing or hardening `GET /save` (no cookie GET state-change). Strip F2 `proof` from save/list responses.

### C6-F03 / C6-F04 — Info

Upstream snippet and CORS credentials are product/lab affordances unless they block hardening. Default: **Accepted residuals** if F01/F02 closed.

### SSDLC extras

Preview rate limit + TLS gate are **Cycle-6 Blue showcase** items (extend existing nginx auth `limit_req` and TLS overlay from earlier cycles).
