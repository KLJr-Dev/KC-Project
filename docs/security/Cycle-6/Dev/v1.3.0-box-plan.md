## Story (one path)

1. Recon product UI — notice **Link Preview** (or equivalent).  
2. Abuse server-side URL fetch → **SSRF** to an internal target → capture SSRF flag / sensitive internal response.  
3. Separately (or in parallel): find a **cookie-auth state change** that lacks CSRF protection → forge request from attacker origin → CSRF flag / impact.  
4. Stop. No shell, no PrivEsc, no AD.

```text
Browser → nginx → Nest Link Preview (open fetch) → internal prize
Browser (victim session cookie) → CSRF-gap mutation → impact plant
```
