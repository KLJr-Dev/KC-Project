## Per-finding detail

### F-01 — Unauthenticated Swagger

**v1.0.0 state:** `/api/docs` + `/api/docs-json` open; descriptions advertise CWEs.

**v2.0.0 change:** Register Swagger only when `NODE_ENV !== 'production'` (or `ENABLE_SWAGGER=true`). Neutral operation summaries.

**Files:** `backend/src/main.ts` (DocumentBuilder / `SwaggerModule.setup`).

**Verification:**

```bash
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/api/docs
# expect 404 (or 401) on prod stack
```

---

### F-02 — Horizontal IDOR (files)

**v1.0.0 state:** Any JWT reads `/api/files/9104` + download.

**v2.0.0 change:** Every get/download/delete checks `ownerId === req.user.sub` (admins may bypass via explicit role check). List endpoint returns only owned files (or paginated admin view).

**Files:** `backend/src/files/files.service.ts`, `files.controller.ts`; DTOs if `storagePath` still leaked (baseline CWE-200).

**Verification:**

```bash
# user token → 403
curl -sS -w "\n%{http_code}\n" -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:8080/api/files/9104
```

---

### F-03 — JWT role forgery

**v1.0.0 state:** HS256 `kc-secret`; guard trusts claim.

**v2.0.0 change:**
1. Secret/keys from environment (no repo constant).
2. Prefer RS256 per baseline.
3. `HasRoleGuard`: load user by `sub`, compare **DB** role to `@HasRole` metadata.

**Files:** `backend/src/auth/auth.module.ts`, `auth.service.ts`, `guards/has-role.guard.ts`, `jwt-auth.guard.ts`, `jwt-payload.interface.ts`.

**Verification:** Forge `role:admin` with old/new secret → admin routes **403** unless DB role is admin.

---

### F-04 — Public share tokens

**v1.0.0 state:** `share-${id}`; unauth GET returns bytes; expiry ignored.

**v2.0.0 change:** Random token; check `expiresAt`; rate-limit; update seeds/migrations away from `share-1`.

**Files:** `backend/src/sharing/sharing.service.ts`, `sharing.controller.ts`, `migrations/*SeedDemo*`.

---

### F-05 — Exposed PostgreSQL

**v1.0.0 state:** `5433:5432`, defaults `postgres`/`postgres`.

**v2.0.0 change:** Remove host port mapping from prod compose (backend uses service name `postgres:5432`). Strong password via secret/env; document that missing `infra/.env` must not silently use lab defaults in “secure” profile.

**Files:** `infra/docker-compose.prod.yml`, `infra/.env.example`, deploy docs.

**Verification:** `nmap` host — 5433 closed; app health still OK.

---

### F-06 / F-07 — Headers & CORS

**Files:** `infra/nginx.conf`; `backend/src/main.ts` (`enableCors`).

---

### F-08 / F-13 — Auth & error disclosure

**Files:** `backend/src/auth/auth.service.ts` (login messages); global exception filter if any; strip version tags from guard messages (`jwt-auth.guard.ts`, `has-role.guard.ts`).

---

### F-09 — Session lifetime / logout

**Files:** `auth.module.ts`, `auth.service.ts`, `auth.controller.ts`; new TypeORM entity + migration for refresh tokens (per baseline).

---

### F-10 — Admin authz gaps

**v1.0.0 state:** User JWT → audit-logs 200; DELETE user 204.

**v2.0.0 change:** `@HasRole('admin')` on both handlers; ensure `HasRoleGuard` runs (already on controller class — metadata was the bug for DELETE).

**Files:** `backend/src/admin/admin.controller.ts` (+ soft-delete/cascade in `admin.service.ts` if present).

**Verification:**

```bash
curl -sS -w "%{http_code}\n" -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:8080/api/admin/audit-logs
# 403

curl -sS -o /dev/null -w "%{http_code}\n" -X DELETE \
  -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:8080/api/admin/users/11
# 403
```
