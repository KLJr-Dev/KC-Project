## Why rails were reset (P0)

Before Cycle-4, `origin/backend`, `origin/frontend`, and `origin/dev` still pointed at **early-2026** SoftDev tips (hundreds of commits behind `main`). Using them as-is would recreate merge hell and risk resurrecting pre-v2.1.0 insecure patterns onto the Notes work.

**P0 policy:** SoftDev long-lived branches are **recreated from current `main`** at the start of each SoftDev security cycle. History on the old tips remains reachable via reflog/old SHAs if needed; the branch *names* mean “current SoftDev work for this cycle,” not archival CTF freezes (`ctf/*` / `remediation/*` fill that role).
