# Cycle-4 player brief — `v1.2.0` (Notes → SSH foothold)

**Audience:** Red players / students  
**Spoilers:** Progressive hints only — no flag values, no passwords.  
**Examiner GT:** [v1.2.0-ground-truth.md](v1.2.0-ground-truth.md)

---

## Objective

Reach an SSH foothold and recover the user flag. Stop there — **no PrivEsc** on this box.

Checkpoints (format `OS{` + 32 lowercase hex + `}`):

| ID | Theme |
|----|--------|
| F1 | Web / Notes render |
| F2 | Privileged note content |
| F3 | SSH user home |

## Lab start

```bash
docker compose -f infra/docker-compose.prod.yml -f infra/docker-compose.ssh.yml up -d --build
```

- App: `http://localhost:8080` (or the box IP on `:8080`)
- Demo accounts: see [demo-users.md](../../../deploy/demo-users.md) (`user@kc.test`, `mod@kc.test`, `admin@kc.test`)
- SSH is **not** on the default prod compose alone — look beyond the web port.

## Rules of engagement

- In scope: Notes, auth/RBAC as needed, SSH foothold, home loot
- Out of scope: PrivEsc / root, published Postgres, DoS, attacking other students’ boxes
- Do not “fix” XSS or remove SSH — this tip is intentional SoftDev insecure (`v1.2.0`)

## Progressive hints

<details>
<summary>Hint 1</summary>
Look beyond TCP/8080. Full-chain lab deploys an extra service.
</details>

<details>
<summary>Hint 2</summary>

<details>
<summary>Hint 3</summary>

</details>

<details>
<summary>Hint 4</summary>

</details>

<details>
<summary>Hint 5 (almost spoiler)</summary>
Primary path is Notes XSS / privileged read → real bastion material in an admin ops note → SSH → `user.txt` (and clutter in home / `.bak`).
</details>

## Deliverable

Writeup with identity proof + F1–F3. Stop at foothold (Cycle-5 covers shells/PrivEsc).
