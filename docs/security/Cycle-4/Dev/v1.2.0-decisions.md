### Clarify — attachments (§1)

**Suggestion (adopt unless you object):** `POST /api/notes` may include multipart `attachment`; stored under uploads; insecure tip serves/displays attachment inline where type allows XSS (e.g. `image/svg+xml` or HTML). Secure `v2.2.0`: Content-Disposition attachment + MIME allowlist + no inline SVG script.
